## Change

The initial REAL021 parse/semantic path exceeded four seconds. Breaking down the original path showed that semantic interpretation and final validation, rather than the upstream parser, accounted for its longest non-cancellable intervals. A cancellable Gerber entry now checks at command, macro/aperture and semantic-validation object boundaries. Cancellation is a distinct error and cannot trigger the compatibility fallback. Existing parsing APIs use an always-false callback; successful documents are compared byte-for-byte through their semantic serialization/equality. No geometry rule, resource budget or dependency changed.

Import still prepares a private batch and uses the existing CAS immediately before its one history transaction. Cancel and commit remain mutually exclusive. The app releases the rollback view before marking a task terminal. Committing shows an explicit non-cancellable message; invoking Cancel then reports TooLate and waits for the real result. No cancellation rollback is attempted after commit.

Tests independently vary all six input/current/result identity dimensions. They cover edit, Undo, Redo, workspace changes, close/replacement and service revision differing from a cached view. Parser and exact selection cancellation occur inside their loops. Scene cancellation injection is test-only and thread-local: after two actual scene objects are built it cancels the real token, checks zero result publication and old Arc preservation, then verifies a subsequent rebuild succeeds. Product and internal-evidence binaries do not contain that injection.

## Portable verification and freeze protocol

`scripts/run_s5m2_native.py --binary <release-internal-binary> --fixture <local-large-Gerber> --evidence <new-directory>` uses explicit local paths, isolated native settings and three consecutive rounds. The fixture is hashed, not copied. Source and Evidence verification is read-only: `python3 -B Source/scripts/verify_s5m2_evidence.py --source Source --evidence Evidence`. The verifier binds full commit (including embedded Mach-O commit bytes), clean source/package manifests, both release binaries, raw native records/images, all gates and the ordered 18-case matrix. Runner timeouts fail even if termination returns zero; nested unmanifested files and substituted gate commands are rejected. It rejects missing/tampered records, duplicates, traversal/symlinks, nonfinite JSON, dirty/mismatched identity, failed gates, partial publication and timing violations. Unit fixtures are explicitly synthetic verifier tests and are not native evidence. Hash consistency cannot authenticate an observation; independent review must inspect raw native images/events and build provenance.

This source review deliberately does not declare final PASS. All gates must actually pass, the parent must independently approve the complete candidate, and only then may the phase be committed without push. After commit: verify clean status, clean release builds, re-run identity-bound evidence, generate same-commit Source/Evidence packages, and verify fresh extraction. The versioned package review records the resulting full commit and artifact hashes without changing/relabeling this source afterward.

Windows, K1 native debt, M2-B drag/performance, PMIX/PSTRESS, full CORE10/V1 and CircuitCAM compatibility remain deferred/not executed. No later phase is started by this closeout.
