## 参考边界和差异处理

参考审查报告的是 CircuitCAM 的圆光圈折线笔画，不能当作 TTF 填充字型或简单包围盒缩放模板。用户已澄清参数为“线宽×名义字高”，`0.3×5` 即线宽 `0.3 mm`/字高参数 `5 mm`；此前底排明确纠正为 `0.5×10`。字形、线宽和间距以附件实际几何为准，中排不强制错误的 `0.5×5` 标注。审查报告中排实际线宽 `0.8 mm`、中心线相对上排约 `1.6`；对应名义字高 `8 mm` 是待标定推断，不是用户明确确认的输入值。名义高度与全字符 bounds/大写主体高度存在区别。后续应分别建立中心线节点/advance/基线/伸部和最终带线宽圆头连接的真值；不把错误标注转换成通过标准。

该参考不足以验收空格、换行、Tab 或非 ASCII；未在此文档公布字形坐标、原图形、私有标识/文件名/路径/哈希或机器日志。新的量化比较容差尚未冻结。字型来源/许可、系统实际可用性、缺字、身份变更兼容、资源/任务 fence、原子历史、独立导出重开与 Mac/Windows UI 属于后续实施合同和验收，当前均不据此次只读库存判为通过。
