# art08 显示倍率恢复记录（2026-09-24）

阶段：S4-B3 后显示缺陷闭环；关联 R08/R16/R17/R19，AT-023/024/025，以及工程保存 R15/R21、AT-041/093。改动涉及 `editor-app` 的输入、显示索引、GPU 准备与回归测试，以及 `editor-service`/`rcam-project` 的工程往返。此记录不将完整正式 AT 用例或双平台 V1 标为通过。

## 用户复现与原因

在已运行的 macOS RCam 中，隐藏 `0727SMT/75/ea1hs2m01MAN_VB/art08.art` 图层，改变画布倍率，再取消隐藏。窗口中的原文件仍保留在图层列表，但画布空白；状态栏显示 `RESOURCE_LIMIT: resource=candidate_sample_work limit=2000000000 actual=2466986816`，触控板捏合后倍率不变。

显示准备按复杂 Region 所有屏幕行都经过最密集的 Y 分箱计费，误判实际工作量；较粗的空间索引和最多 256 个多边形分箱放大了估算值。视口已扩出 2 px，索引估算仍给每个网格单元重复增加边缘余量。短圆弧按完整圆包围盒进入索引，使大量无关对象成为候选。失败路径又把相机回退到上一帧，因此无法靠继续缩放脱离错误状态。原生触控板事件在没有悬停指针时也会被画布悬停条件忽略。

## 修复

- 多边形按每个物理像素行能触及的 Y 分箱边数估算显示工作量，并覆盖相邻行与分箱的采样相位余量；填充对象只按实际抗锯齿采样范围计费。极高倍率下，Region 为左右射线分别按 X 坐标排序边，在像素一侧不可能有交点时提前结束扫描；原始轮廓仍用于独立参考渲染。`candidate_sample_work` 20 亿上限保留。
- RenderIndex 使用更细的有界网格，对局部十余对象的高倍率场景也保留最少 4096 个网格单元；索引估算不再给每个单元重复加视口余量。Region 显示分箱最多 4096 个，总显示项、单元引用与单元对象预算仍生效。短圆弧采用制造语义算出的实际扫掠包围盒建立显示索引。以上只影响显示，不从 GPU 数据反推制造语义。
- 显示准备失败时保留最后可用画面和诊断，但相机不再回退，允许继续移动或缩放恢复。原生 `Zoom` 事件即使没有悬停指针也以画布中心为锚点；有悬停指针时仍以指针为锚点。
- 回归用原文件执行隐藏、改倍率、显示图层，在多级倍率检查 Scene、索引和显示准备；另用原生恢复工程中的两份 `art08` 和 `EP11BAM` 同时显示，检查 17.41/20.31/1017.15 点/mm 及平移。

同一原生窗口尝试保存当前未保存的多图层工程时，还遇到 `INVALID_ARGUMENT: project roundtrip mismatch`，未覆盖原件、未丢弃窗口。原因有两项：默认 JSON 解析使计算所得的圆弧圆心坐标发生一个 ULP 的变化；导入新图层置顶后，工程快照层数组仍按文档插入顺序，而解码按显示顺序还原。启用锁定 `serde_json` 的 `float_roundtrip` 特性并按 `layer_order` 构建工程快照，继续执行严格字节编码后重开一致性检查。

## 验收结果

原件只读，SHA-256 为 `7854e6497f6fcb5d94c2dc2e4019c8ea303a33752be0fe0589ec1ba48fb44e6b`。真实文件回归按隐藏→改变视口→显示执行，8/32/40.62/128/200 px/mm 均构建 Scene 且 `gpu::prepare_measured` 成功；加入 EP11BAM 真实第二图层后同样通过，并完成 `.rcam` 保存、重开。四图层恢复工程的两份 `art08` 同时显示时，17.41 点/mm 的原位置、四向各平移 2 mm、20.31 点/mm，以及 1017.15 点/mm 的原位置及左右各平移 0.1 mm，均低于原有 20 亿限制；详见 `recovered-pan-zoom-final.log`。左右射线填充对照用例与 macOS Metal 参考渲染逐像素 RGBA 用例通过，见 `metal-parity-native-final.log`。首次全套测试中旧密集视口用例仍要求拒绝，调整为验证现可接受的工作量后通过，失败与通过日志均保留。

原生旧版窗口中的自动恢复快照经 SHA-256 核对，复制到 `/tmp/rcam-art08-recovery-backup-20260924.rcam` 备用；不纳入公开证据或交付 ZIP。独立的 macOS Metal 测试窗口打开由应用服务保存的高倍率工程副本后，17.41 点/mm 显示实际图形，无资源限制提示；从画布滚动平移后，图形从密集线路区域移动到板边定位孔区域。用户继续放大后在 1017.15 点/mm 再次遇到 `actual≈35.6 亿` 的暂时无法显示，本轮已补充该倍率的定向回归。最终原生窗口在同一 1017.15 点/mm 工程视角显示图形，画布滚动后图形位置变化，倍率保持不变，状态栏无资源限制。原始日志存于 `evidence/art08-zoom-20260924/`，交付归档置于版本化 `exports/` 子目录。
