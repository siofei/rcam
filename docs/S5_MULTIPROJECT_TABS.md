## 本片合同

- 首片保护策略暂设单窗口最多八个已登记会话：每份保留真实文档、Undo、UI/CPU缓存及控件状态，限制同时持有的记录并留出原通道任务预算；尚未资源压测，不承诺总内存界限。数字可在后续明确资源预算/压测后调整，不是用户指定要求或永久产品硬上限。一个 worker/service 和全局 Scene serial。新建/打开创建独立记录；不替换或关闭原工程。活动页签接收命令，保存、关闭、错误及未保存确认都显示并绑定该工程。
- UI 文档状态完整移动，包括 View/选择、相机、网格/Snap、工具及全部草稿、交互、待处理任务/归属、保存关闭 Intent、恢复计时和 CPU cache。编译时完整字段分类防止新字段漏隔离。egui Memory 随页签移动，窗口全局 options 保留。切换时移动完整状态；inactive 恢复调度/回执通过短暂 owner adapter swap 进入原逻辑后立即恢复活动状态，逐帧不克隆文档。
- 制造写入、确认弹窗、IME、交互及未知终态尚未解决时不切换。可取消只读任务须收到原终态后才切换；切换帧不把原输入重放给新工程。迟到/重复/外工程回复仍须通过 owner/binding、原 receipt/version/selection fences。断线使整个窗口停止新请求。
- worker 新登记验证 namespace、单调不复用 slot 和初始 generation；请求失败不能复用身份。Close 的确切终态才释放登记和 UI 状态。失败新开不损坏既有页签。
- 每会话有独立持久恢复记录 key，metadata 可兼容读取旧单工程记录；写入、发现、加载及清理都绑定记录 key，不能仅按 ProjectId 删除。恢复副本保持未保存/dirty，不继承原保存路径。
- 保存与打开在 worker 上检查其他会话持有的规范路径和已有文件身份（包括软/硬链接别名），拒绝跨会话覆盖；不在 UI 解析工程。既有外部修改检测、同目录临时文件/原子替换和权限规则继续执行。
- 退出依次通过每工程原保存/放弃/取消流程。取消停止退出；错误或未知写入终态阻止退出。未解决的工程不会随其他页签关闭而消失。
- inactive 恢复沿用既有 30s/60s 触发，逐帧公平轮询一个工程，后台回执安装到其 owner；不是后台保存。恢复采用不可变内容快照和最后提交的 metadata，独占持久记录标记防止跨运行复用；旧标记留作不可复用 tombstone。恢复候选为窗口目录入口，成功恢复的来源绑定新工程，明确保存/关闭时精确清理；拒绝/失败保留可重试入口，“稍后”保留磁盘副本，页签栏可重新查看恢复目录，不强制删除快照腾位。
- 最后一个工程关闭后保留空登记页签，但完整丢弃已关闭工程的 UI/缓存/控件状态；其余关闭以确切 worker retirement 回执回收页签。
- 不在此片加入 split view、跨工程剪贴板/事务、多文件批量打开或 inactive 后台保存。后续扩展另需资源和并发合同。
