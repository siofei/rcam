## Concrete behavior

`geometry.selection_centers` is a typed and JSON, revision-bound read-only ApplicationService query. It receives explicit layer/object groups and `selected_layer_composite`. Bounds include selected source manufacturing boundaries; area/moments/perimeter use only the selected material, each layer's original exposure sequence, local aperture holes/Macro transparency and in-place Block child exposure expansion. It returns a genuine area centroid, proved ZeroArea or a structured unavailable result without AABB fallback. Canonical selection identities, document lifecycle/revision/precision and bounded LRU cache are retained through edits/Undo/Redo.

The GUI requests this query in its existing worker, without setting foreground busy or replacing selection/display state. UI installation checks the full TaskVersion, request/selection epoch and actual result DTO. It only merges measurement fields. A measurement does not supersede a pending viewport reply; a user action or requested viewport rebuild cancels a pending measurement. The existing numerical/transform UI and legacy independent-object metric panel remain until B/C consumers are connected; this foundation does not claim the requested bottom status or base-point controls are already delivered.
