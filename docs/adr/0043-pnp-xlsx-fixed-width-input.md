# ADR 0043 — S4-D1 input compatibility: XLSX and fixed-width TXT

Accepted for implementation, 2026-10-01. User supplied five coordinate files and requested aligned parsing. This is a bounded S4-D1 follow-up, not D2 association or placement export.

Reuse the existing bounded ZIP reader and locked quick-xml 0.41.0 (MIT); add only a direct service dependency edge. No Excel runtime, macro execution, formula evaluation, general spreadsheet writer or new format library. Service normal-dependency review accepts only the pinned pure-Rust XML package and existing memchr edge; GUI/GPU/dialog and unknown dependency rejection tests remain. The adapter reads explicit XLSX worksheet/header-row or explicit UTF-8 fixed-width spans into numbered table rows; the existing core PnP validator owns numeric/unit/rotation/Side/duplicate rules. Legacy CSV/TSV API behavior with source=None remains unchanged. An explicit Delimited source supports skipped physical lines and no header. XLSX header_row=0 explicitly means no header. No source files are rewritten or uploaded.

XLSX is a bounded data-only OOXML subset (workbook extLst metadata is skipped as a bounded subtree, including Office2018 calcFeatures; no sheet-cell namespace relaxation): shared/inline strings and raw numeric/boolean cells; formulas, errors, explicit date-typed cells, macros, external sheet links, malformed XML/ZIP and unsupported encodings fail closed. Worksheet selection and header row are explicit; headers may propose a column mapping only after a user action. Original headers and up to20 raw rows appear even when business mapping fails. Per-column role selectors let the user assign RefDes/X/Y/Rotation/Side/Footprint/Value or Ignore; only mapped fields persist. Headerless inputs get synthetic labels without dropping the first record. Column-role confirmation is required separately from unit/convention confirmation. Units and rotation convention still require existing GUI confirmation. Numeric text retains original decimal precision; cell display formats are not interpreted as units or dates (a date-formatted numeric cell remains its raw number).

Fixed-width TXT preserves empty Side fields. It never collapses whitespace. Each field uses explicit zero-based UTF-8 byte boundaries, ending at a character boundary. An empty Top or Bottom token is permitted only for this explicitly selected layout. Units declared by the first UUNITS line must agree with the chosen unit. The user confirmed m=Bottom, blank=Top and MILLIMETERS for the supplied TXT on 2026-10-01. When no unit is declared, GUI import requires an explicit manual mm/inch selection and unit confirmation; no inferred/default unit authorizes import. Rotation conventions remain explicit.

Budgets: existing 32 MiB input/normalized text, 100k components, 32 columns, 1024-byte fields and bounded diagnostics remain. XLSX ZIP <=256 entries, <=64 MiB total expanded, <=32 MiB per entry, paths <=512 bytes. XML depth <=64; worksheet row/cell coordinates and aggregate copied text are bounded before allocation. Entire malformed batches return diagnostics and cannot consume IDs/revision/history. Source SHA/provenance refers to original XLSX/TXT bytes, not an intermediate table.

Optional source layout is stored in PnpMapping with serde default/skip-None. Existing v1/v2 files without it keep identical meaning/serialization; new readers restore it. Old strict readers reject the new mapping field rather than misinterpret it. No project version bump is needed for an optional, fail-closed metadata extension; test this compatibility explicitly.

Private real inputs/evidence stay ignored. Commit only independent synthetic data and regression tests. Windows and physical alignment remain unexecuted. No automatic board registration, Bottom reflection, footprint association, production Gerber output or D2 work.
