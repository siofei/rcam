# ADR0053 — PMIX workload and evidence boundary

2026-10-03, accepted for implementation by explicit M2-C task authorization.

Design §14's 40k Flash/30k Line/20k Arc/10k 16-edge Region is the authoritative
100k PMIX performance workload. Freeze deterministic input coordinates and exact
source order before measurement. Text/blocks/multilayer/local polarity need an
additional fixed workflow project; they cannot replace the main data. PPOL,
PSTRESS and device recovery retain independent later stages.

Keep Manufacturing f64 mm and existing A2/M2B service/transaction contracts.
Correctness uses analytic manufacturing witnesses plus the existing native Metal
ordered reference, not renderer-derived manufacturing. Current analytic display
has one full-screen triangle per draw and no per-object triangle mesh; report raw
primitive/point counts honestly instead of inventing tessellation statistics.

Freeze C_PLAN budgets and trajectories before first performance result. Extend
existing point/box, memory and Undo/Redo budgets as explicit local PMIX gates;
do not rewrite the original AT definitions. Preserve all frames, clocks, callback
coverage, raw output files and identities; rehashed semantic negatives are required.
Only demonstrated B0/B1 defects justify production changes, with affected frozen
A2/B regressions and independent review. No dependency or public API addition.
