# UE-B0: joint geometry and aperture checkpoints

Status: authorized foundation; candidate and native acceptance pending. S5/P3 UE-B0; R04/R05/R09/R10/R11/R13/R14/R16/R17/R18/R21/R22; compatibility AT-030/037/039/040/041/042/043/064/065/066/067/078/086/089/090/092/093. Modules: core edit/draft, typed service session, existing worker preparation, synthetic tests and this ADR. Exact independent parent is the frozen confirmed-Gerber candidate; no change to that candidate or saving.

A checkpoint owns its selected geometry and immutable private AP definitions together. Entry references original definitions. Preview, Execute, Undo, Redo and Reset prepare the exact prospective checkpoint before publication. Definitions copied for a target subset never replace the original AP. Private lineage refers to actual source AP identity, never DCode; unrelated imports stay separate. Definitions without live checkpoint references are removed from that checkpoint, while older history retains its original definitions.

The host-only `DraftApertureSizeStep` supplies absolute **AP rectangle width/height** through the existing `resized_shape` validation. It preserves the flash transform and the existing circular hole, as the existing numeric/grip operation does. It is a narrow foundation probe, not a size-dialog contract: no GUI, four-edge/percentage/area operation, centroid computation, world/local axis inference, nonuniform hole deformation, generic shape conversion or definition-editor policy is introduced. Per-object/whole selection, world/local direction, nonuniform hole handling and area-centroid composition remain awaiting explicit user decisions. Technical proposals must not be described as confirmed preferences.

Each temporary ID binds a checked process-local draft namespace, accepted input generation and authoritative slot. Collision with source or another overlay is refused. Repeated Preview/Execute of one input consumes no ID counter. DCode is assigned after live-reference pruning; discarded private definitions cannot exhaust prospective DCode space. Main generated IDs/DCode are planned only at Apply, and main counters advance only after Changed publication. Shrinking back to the exact original shape restores the original reference. Residual geometry transforms still yield Changed; exact entry equality yields NoChange, preserving main history/Redo/revision/dirty/counters.

Apply maps **all** live definitions and flash references to final identities before its preparation callback. The worker overlays these definitions before WorldIndex, Scene, GPU validation and selection construction. A single top-level transaction owns the global definition insertions and all per-layer geometry deltas. Forward and reverse guards check the complete transaction before mutation; forward adds definitions then changes geometry, Undo restores geometry then removes definitions. This is one cross-layer commit, not a sequence of layer-level COW commits. Redo restores exact definitions, identities and geometry.

Core accounting includes unique Arc checkpoints, AP vector capacity, base/definition IDs, candidate maps and final-ID rewrite copies. Count-first admission precedes candidate allocation; history and final transaction are charged independently. Host admission counts new AP definitions **and each flash reference** before cloning a snapshot. Rectangle topology and circular-hole shape stay unchanged, so the existing source-derived primitive reserve remains conservative; no new shape family is admitted. Pure transform checkpoints allocate no new AP slots, and empty-overlay host preparation preserves its previous resource charge. Existing 64 MiB/100-entry core and 128 MiB/2-second host contracts stay unchanged. Accounting is not a process/GPU RSS or cancellation-latency guarantee.

Failures in validation, resource admission, prospective preparation or the cancellation/publication barrier retain work, history and main state. Existing service ownership/revision/workspace/permission checks and request/ticket fences apply. Cancel discards the private definitions with the draft; Reset retains the window's session and restores entry. New typed host commands are not JSON capabilities or product UI features. Saving, shaders, Snap/Alt semantics and manufacturing schema are unchanged.

Required regressions cover cross-layer final preparation identity and one Undo, actual import namespaces and unselected instances, subset COW, joint history/Reset, exact NoChange with main Redo/counter preservation, residual Move, repeat-preview identities, overflow/collision, preparation/cancellation refusal, stale/foreign service, resource refusal and real worker Scene/index/main consistency. Source/gate/independent package evidence is retained separately. Auxiliary CPU tests do not replace Mac/Metal native acceptance or close unrelated earlier JSON errors. No full-stage PASS is asserted.
