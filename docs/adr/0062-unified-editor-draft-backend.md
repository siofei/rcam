# ADR0062: bounded accumulating manufacturing draft (backend preparation)

Status: unpublished CPU backend preparation on the exact cb9 product source; no UI integration or native acceptance. S5/P3, R05/R09/R10/R11/R12/R16/R17/R18/R21/R22; compatibility AT-030/031/034/035/036/037/038/039/040/041/043/064/065/066/067/078/086/089/090/093. Allowed modules: editor-core/edit and editor-service, synthetic CPU regressions and contract documentation.

The typed host-only session keeps selected f64 manufacturing geometry, stable layer/object slots, and immutable entry geometry. Read-only entry/work views never permit replacement geometry. Move/Rotate/Mirror parameters are the only input; each calculation starts at the current executed work, never the previous preview. Definitions remain in the original service record and are protected by service namespace, document lifecycle, manufacturing revision, and workspace revision fences. No second service/document copy or main-history trial edits.

Internal Undo/Redo retains exact Arc checkpoints, with one shared entry and bounded history. Reset restores entry and clears checkpoints, pending parameters and previews; Cancel releases the entire draft. Each input carries its working generation; successful Execute advances it and invalidates the same input token. Each step explicitly selects a valid subset of entry, including complete generated text groups. All original validation, unsupported transforms, permissions and geometry budgets apply.

Final Apply has an explicit opaque pending ticket. While pending, input/preview/Execute/history operations are refused. The worker completion calculates the latest unexecuted typed input through the same core calculation as Preview/Execute, even if no preview was requested. It validates the final entry-to-work deltas and creates one cross-layer Operation::Selection; it never loops single-layer commits. All checks precede commit and cancellation's begin_commit barrier. Failure preserves both main state and draft work/history/input. Exact manufacturing equality yields NoChange and closes the draft without revision, dirty or main history mutation. Successful Changed also closes; stale/repeated tickets cannot commit. Reset/Cancel invalidate outstanding tickets.

Resource admission measures unique checkpoint capacities (strings, geometry vectors and Arc/vector bookkeeping), plus typed input storage. Conservatively reserve the existing checked MoveDemand work charge for lookup maps, resolved Block scratch, before/after/commit copies, plus a new full candidate checkpoint. This reserve is added to draft resident charge, rather than falsely treating a single MoveDemand as the entire session. Both pre-allocation conservative admission and post-allocation capacity checks precede installation. Draft resident plus reserved temporary peak uses the configured existing manufacturing history byte cap (default 64 MiB); checkpoint count uses its configured entry cap (default 100), and each step uses the existing ordinary transform selection cap (10,000), not the enlarged Move-only cap. Main Undo retains its independent existing cap. These are engineering reuse of existing boundaries, not user-supplied constants or a total process RSS guarantee. Record real synthetic snapshot/history charges and separately measured worker process peak before freezing publication; allocator/platform/global worker memory remains separate evidence. Refusal never evicts draft history or main data to make room.

Acceptance additions (CPU): accumulation vs repeated input, exact reference and undo/redo/reset, different step subsets, all-layer atomic apply and one main undo/redo, unpreviewed latest input, pending and duplicate ticket rejection, invalid/latest unsupported later-layer failure, stale manufacturing/workspace/cross-service/document lifecycle fences, cancellation before commit, no-change exit preserving main redo/dirty/revision, and byte/history admission preserving previous work. Existing AT meanings and native thresholds remain unchanged. UI/Snap/Alt/layout, device resources, Metal/DX12 and cb9 native regressions are outside this backend preparation.
