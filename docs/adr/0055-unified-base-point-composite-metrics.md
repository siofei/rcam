# ADR 0055 — Unified world point inputs and selection composite metrics

Status: Accepted for implementation, 2026-10-03; validation not executed.

I1 clean f1939fd is the baseline. S5-I2_PLAN freezes scope, selected-only semantics, perimeter, all applicable tool inventory, numerical admission, budgets, performance and native gates. ApplicationService remains the mutation/query boundary; no egui/window/GPU dependency in core/service. Read-only selection metrics neither revise nor dirty a document. Full TaskVersion plus selection/request identity fences asynchronous results. Cache values are world-sensitive composite material results, never independent-object sums.

Choose true line/arc arrangement and local Green integrals with explicit uncertainty over tessellated or raster-derived geometry. Same-layer composition follows exposure order; macro holes are local; Block children act at layer level. Reject unresolved topology/precision/budget explicitly. Area center and envelope center are distinct; neither silently substitutes for the other. Point Pick freezes selection; target Snap excludes moved selection. All edits go through one existing atomic SelectionEdit.

Persistent mouse drag and Grip settings are independent; migration defaults preserve both existing enabled behaviors. Canvas cursor defaults to system. Fixed status slots reserve layout space and obtain composite metrics from background cached service computations. Unreproduced reported menu flicker remains OPEN. No additional dependencies, products, arbitrary-axis mirror, clipboard or PMIX work is authorized by this ADR.

Three coherent stages A/B/C are required; independent review precedes stage commit. No push, no uploads, no directory deletion. Numerical/performance thresholds must not be changed after a failure to obtain PASS.
