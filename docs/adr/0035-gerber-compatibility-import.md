# ADR 0035 · 带警告的 Gerber 兼容导入

日期：2026-09-24。状态：已实施，验收部分通过。阶段：S4-B3 后导入缺陷闭环。关联 R02/R03/R04/R06/R14/R19，AT-005/006/009/015/020/053/080。

## 背景

`EP11BAM-A_top_0mm_202607241511.gbr` 和 `0727SMT` 中有大量可显示但不符合严格 Gerber 语义检查的文件。用户要求这些文件能继续导入、编辑和导出，并对问题给出提示与日志；要求所有客户重新导出不现实。先前的严格拒绝记录保留作基线。

## 决定

1. 严格解析仍是首选；仅严格解析失败时执行兼容解析。兼容解释必须保留源 SHA-256、原始文件、逐类诊断及源命令顺序，不跳过未知绘图命令。
2. 旧式 MI 只变换坐标数据；Flash 光圈局部形状不镜像。单轴反射翻转圆弧方向。前导零 FS 仅扩展整数位，小数位不变；绘图前重复 FS 若小数位相同，沿用首个声明并警告。AM 20 解释为平端矩形；旧式 AM 22 下左角矩形转换为等价的中心矩形；Thermal 7 转换为局部 Dark 外圆与 Clear 内圆/十字缝。宏轮廓源精度内重复顶点可合并；斜向无孔矩形光圈线转换为精确凸 Region。每类转换均记录警告。零直径圆光圈以 2 µm 占位并明确提示尺寸改变。
3. G74 只在源坐标量化造成的边界越象限时采用可证明的 G75 几何解释；Region 未闭合时在源精度以内调整末端，其他情况插入显式线段，缺失起点沿用当前坐标，零长度边移除；空 Region 没有曝光，忽略并警告。每次调整都记录警告。无法证明拓扑规范的轮廓保留为 `CompatibilitySolid`，不宣称其是标准 Region；编辑、显示、导出均读取语义对象，不从渲染网格回推。
4. 兼容图层在列表、导出确认和来源元数据中持续提示。导出先使用工程的 `ManufacturingPrecision`；只有量化会使兼容几何失效时才返回 `CONFIRMATION_REQUIRED`，列出工程及所需分辨率。调用方显式提供 `compatibility_precision_override_mm` 后才可使用更细网格。1 µm = `0.001 mm`，旧实现的 `0.000001 mm` 实为 1 nm；FS 6.6 编码网格不等于制造精度。独立工具/物理制造等价性须另行验收，不能把内部往返当唯一真值。
5. 不规范日期、旧式属性删除记录、空 AD 占位不影响制造几何，忽略时记录类别；非 UTF-8 文本用替换字符解码并警告，ASCII 几何命令不改变；文件尾 DOS EOF 标记可移除。无法确定解释的输入仍报告错误并保留已打开文档。资源预算继续限制内存及输出大小；扩容本身需留存批量日志和回归结果。
6. `0727SMT/107/202607274351/drill.art` 实测 803226 个语义对象，超过旧 500000 上限。把解析、编辑、RenderIndex 和 `.rcam` 单层对象预算一致提升至 1000000；导出重解析需要超过旧 2000000 命令预算，因此将命令预算提升至 4000000。原文件约 20 MiB，但规范化导出约 46.6 MB，需可重开，因此把源文件上限调至 64 MiB。Region 边 2000000、显示引用 1000000 和导出 64 MiB 上限仍独立生效。提升依据是本地实测，不推导百万对象的 GUI 性能门槛已通过。

## 验收

保留 0727SMT 候选清单和每轮逐文件 STRICT／COMPAT／REJECTED 记录。对指定 EP11BAM top/bottom、AM20、MI、FS 溢出样本执行原件只读哈希、解析、编辑、导出、重开与显示检查。96 个正式 AT 用例、CORE10、Windows 和双平台 V1 结论不因本 ADR 自动改变。

## 2026-09-24 补充：零直径光圈的制造语义

`%ADD...C,0*%` 没有有面积开口的可靠制造语义。完整的 `CompatibilityZeroAperture` / ZeroWidth 模型需要同时约束 Flash、D01、选择、显示、工程编码和 Writer；本轮保留显式的有损 Circle 占位转换，不把它称为原始制造尺寸。占位直径为 **2 µm = 0.002 mm**；旧代码 `0.000002 mm` 实为 2 nm。导入问题保存在 `SourceMetadata.compatibility_issues` 并随 `.rcam` 往返；图层及导出确认必须指出制造面积已改变。未确认兼容问题不得导出 Gerber。确认后的输出是用户选择的转换结果，不能宣称与原始 C,0 制造等价。独立 CAM 对照若有差异，该类图层只能留在 `.rcam` 查看/编辑，不能批准生产规范化导出。

严格解析失败时仅 `Syntax`、`Semantic`、`Unsupported`、`InvalidUtf8` 可重试一次兼容解析；`ResourceLimit`、`Io`、`TargetExists` 不回退。兼容解析自身仍对未知或不确定内容拒绝。`CompatibilitySolid` 不等同规范 Region，导出确认显示数量、图层和问题类别；外部 CAM 几何比对完成前不授予生产等价结论。
