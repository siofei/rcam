# ADR 0008：Mac-first S1-B1 编辑闭环

日期：2026-09-15。依据用户指定 RCam_MAC_FIRST_S1B_NEXT_TASK.md；前置提交 4bf84a0。
任务中的 rcam-s1a1-20260915-4c18470b 是交付标识，本次实际 Git 父提交如上。
阶段 S1-B1；R01/R04/R10/R11/R14/R15/R19/R21/R22。
关联 AT-013/014/030/039/040/041/042/054/086/088/089/090/091/092/093/095/097 的局部检查。
允许修改 editor-core/editor-service、editor-app 服务生命周期、gerber-io 的模型构造适配、
相关测试、设计/验收/API/能力/审查文档、源码清单；不扩展解析范围或重写渲染。

当前开发和阶段门禁仅 macOS arm64；Windows 延后且保留所有 required_platforms，不能标通过。
此决定覆盖历史报告中“不进入 S1-B”的阶段限制，不覆盖 CORE10、最终双平台 V1 或生产输出门槛。

只实现多对象 Move、Undo/Redo 和已有 Writer 的编辑后往返。历史保存选中对象的前后几何，
不通过逆平移撤销，不克隆整份文档。限制每次 10000 对象、100 个历史事务、64 MiB 保守计费；
超过预算拒绝整个请求，不静默删历史。Redo 分支只在新编辑提交成功后清除。
同文档由服务 &mut self 串行执行，所有成功编辑/Undo/Redo 推进 revision；溢出拒绝。
所有对象先生成并验证候选几何再提交，保留 ID、光圈、曝光和源顺序。查询实时读模型，无独立索引缓存。

SemanticLayer 预留真实 locked 状态并在核心编辑入口检查；本轮不开放图层属性修改 API。
增加 document.close 的显式 discard_changes 策略以检查会话历史隔离。导出成功更新内容哈希基线，
失败不改变基线；Undo/Redo 后按当前内容哈希判定 dirty，不以 revision 或栈长度代替。
GUI 只保留长期服务与现有文档身份，不开放编辑按钮。
