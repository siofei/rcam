> 版本：1.1 · 日期：2026-09-14

## 1. 验收如何判定

完整 V1 必须同时达到“数据与几何正确”“实际编辑闭环”“Windows／macOS 真机”“性能与异常”“无界面业务接口可用”“证据可追溯”。不能以功能完成百分比替代关键门禁。

状态只有：**未执行、通过、失败、阻塞、不适用**。缺机器、缺字体、缺样本、缺日志和没有实际执行，都不能填写“通过”。

B0 表示数据安全、制造几何或核心发行阻塞；B1 表示 V1 必需功能／性能缺陷。这里列出的条目全部为必测，B1 不是可忽略。第一版通过需要所有适用用例通过、B0/B1 未关闭缺陷为零。非阻塞视觉瑕疵可以单独列 B2，经负责人书面接受。

“不适用”只允许用于发布范围未包含的额外 OS、未启用的后续功能或确实无对应硬件的补充步骤，并写明依据。不能用它跳过中文文字、核心样本、LPC、保存安全或整个 macOS 验收。缺少 Windows 或 macOS 必要真机证据，只能发布对应单平台预览版。

任何阈值或范围调整必须在开始验收前更新设计、基线和用例；已发现的失败不得通过删用例、改样本或调阈值消除。

**本修订按用户要求取消 Linux 支持，原 AT-079 从有效用例中退役，编号不复用，也不计为通过。新增 AT-085—AT-097 共 13 项，当前为 96 个有效用例、1 项退役记录。** 修订发生在软件验收执行前；这不是通过删失败用例来改变结果。

脚本接口预留必须有真实无窗口调用证明，但不要求 V1 交付 Python／Lua 引擎、正式自动化 CLI、脚本编辑器或控制服务；不得把这些范围外功能当作本次缺陷。

## 2. 本文档包包含与不包含什么

本包包含设计、用例规范、机器可读用例表和 Codex 指导，**不含软件源代码、测试执行器、已经核验的 Gerber 样本、字体文件或实测性能结果**。下表中的样本 ID、文件结构及 `xtask` 命令都是实施阶段需要创建的契约。

`acceptance_cases.json` 和本文件来自同一套用例数据；JSON 的 `schema_version` 为 2，`cases` 保存 96 个有效用例，`retired_cases` 只保存迁移记录。有效用例的 `status` 初始全部为“未执行”。实际运行结果另存到 `evidence/`，不要覆盖原始验收规范来隐藏失败历史。

## 3. 进入验收的准备条件

## 4. 统一测量口径

制造坐标比较使用设计第6节的毫米容差。输出制造量化步长q由文档精度指定，默认q=0.0001mm；FS编码仍为0.000001mm（ADR 0026）。每轴舍入误差≤q/2加浮点余量。字体贝塞尔转制造轮廓的最大偏差≤0.001mm。显示细分的0.35物理像素误差不允许被带到Gerber保存中。

性能按设计第14节：release、固定画布、预热10秒、固定60秒交互、A/B各重复3次，保留全部数据。表中的p95／p99是冻结采集口径的百分位数，不是用平均FPS换算出来。每次运行都要达标，不只选择最佳一次。

栅格比较必须固定物理窗口与坐标对齐；小开孔、细缝、孔洞和连通区域单独核查。不允许以“整体差异小于某比例”掩盖一个关键开孔丢失。无法独立验证的差异记阻塞。

## 8. 从第一次启动到业务验收的推荐执行顺序

先跑A/B构建与最小几何测试，再验证极性、孔洞、范围外拒绝和往返；这些通过之后才验GUI选择和变换。接着完成中英文加字与故障保存、GUI共用接口与无界面往返，再跑固定性能和双平台发行，最后跑CORE10全流程及最终报告。

某项几何／文件安全用例出现B0失败，应立即停止使用该构建输出生产文件；保留最小复现、输入输出和日志，修复后重跑受影响模块及全部B0回归。不建议继续大量人工测外观来堆“通过数量”。

### 8.1 第一版业务演示脚本

使用CORE10中一份冻结文件：打开并检查单位 → 选择指定对象数 → 数值移动(+5,-3)mm → 复制到指定偏移 → 镜像一段圆弧 → 创建“钢网W1234567” → Undo／Redo → 另存为新Gerber → 完全退出程序 → 重开导出 → 独立工具核对关键尺寸、字洞和修改位置。

业务演示必须同时提供录像和真实输出Gerber。录像中的文件哈希要与送验输出对应，不能换成另一个手工制作的文件。

### 8.2 接口预留演示流程

不启动窗口或 GPU，以真实服务打开 F_API／F_EDIT → 查询图层和几何对象 → 使用显式毫米参数编辑 → 触发一次版本冲突／批次失败并验证零修改 → 使用固定字体创建文字 → Undo／Redo → 无弹窗导出到新文件 → 重新打开并独立复核。

同一业务步骤再由 GUI 完成，比较制造几何与曝光结果。两平台分别提供实际请求、返回、输出与日志；不能用 mock 成功、只解析 JSON、伪造脚本截图或调用 GUI 按钮替代此流程。
