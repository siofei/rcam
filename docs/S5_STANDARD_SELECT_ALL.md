## Defaults and configuration protection

- New configurations bind only Primary+A: macOS Cmd+A, Windows Ctrl+A. The shared command catalogue already has this logical default; remove the app's special Mac Secondary default. Menu and shortcut retain the same SelectAll action and complete visible/selectable/unlocked snapshot filtering.
- An existing schema1 entry is ambiguous: a saved default and a user explicitly choosing the same key have identical bytes. Preserve every present unmarked entry, including empty/custom/old Ctrl+A. Preserve its historical cross-platform effective mapping, source platform and raw keys. Loading does not rewrite the file. An old Mac configuration may consequently still show Ctrl+A; select the All command and restore its default to adopt Cmd+A. This is protected legacy configuration, not a new default alias.
- New optional entry field `select_all_origin` is allowed only for `edit.select_all`. `default` requires exactly Primary+A; new configuration, missing entry and explicit restore use it. `custom` marks explicit confirmation or clear, even if the keys equal the default. New marked entries use ordinary logical modifiers, without the legacy physical-Control heuristic. Recording/editor preview represents an explicit custom choice.
- A missing entry acquires Primary+A unless it conflicts with a present custom command. Then it stays empty and unmarked; it never silently regains a key on restart. Explicit restore rejects a collision without changing either command. Validate both raw and effective cross-platform conflicts; invalid/unknown provenance rejects the whole configuration.
- Existing schema1 files remain readable with no provenance field. Newly written marked files add an optional field under schema1. Older application versions with strict unknown-field rejection cannot read that extension and protect the file/use their fallback rather than silently changing it; this is one-way reader compatibility. Export/import uses the same bounded parser and atomic/fingerprint-safe store. No startup reset, save-format/project-schema migration or unconditional disk rewrite.
- Text editing receives standard command+A for selecting text. IME composition, shortcut recording, open modal/popup, disabled/busy context and inactive window retain input ownership. Physical Ctrl adds and Shift removes canvas selection as before; Command-click on Mac remains Replace. No change to selection permission filters or one-Undo editing.
