# 快捷键设置与迁移（S5-K1 candidate）

打开菜单“设置 → 快捷键设置 / 导入导出”。可按名称、稳定命令 ID 或当前键查询全部可配置命令（包括后续扩展项）。左列显示功能名称与当前绑定；悬停查看完整名称、别名、分类、作用域及默认绑定，选中后右列显示可滚动明细。小窗口可横向及纵向滚动。固定 Esc 安全取消不可修改。

选中命令后先录制组合，再“加入绑定列表”，最后“确认此命令并自动保存”。一项最多四个别名；“清除此命令绑定”禁用该命令的键盘入口，菜单功能仍按原权限工作。“此命令恢复默认”只恢复当前项；全量恢复有明确确认。关闭设置或切换命令丢弃尚未确认的候选。没有全局草稿 Apply；交换冲突键须先清除其中一项。冲突同时检查可交叠作用域，非法/保留组合不会保存。

录制时 Cmd+S、Delete、F3 只成为候选，不执行业务命令；Esc/取消按钮取消录制，裸或 Shift+Tab 结束录制并导航。IME 组成期间不录制；结束后先释放按键再重新按下。全选默认使用物理 Ctrl+A，可自定义。Cmd 是 Primary，Ctrl 是 Secondary，Option 是 Alt；Windows Primary 映射 Ctrl、Secondary 映射 Win，但本版本拒绝 Windows Secondary 组合。不会修改 OS 设置或抢占已知保留组合。

配置自动保存在当前应用用户配置目录的独立 `shortcuts.json`，旁边为既有 `preferences.json`。常规保存无需选择路径。导出通过原生文件对话框写入完整 JSON，文件只包含版本、平台和命令绑定，不包含项目、最近文件、绝对用户路径。显式空列表表示禁用；快照保持来源平台字段，逻辑修饰键按接收端映射。

导入通过原生文件选择并完整校验，然后显示“完整替换”预览，包括变化、清空、补缺、默认退让及跨平台说明。确认才原子保存并即时生效，不会合并接收端旧自定义项。未知版本、命令、字段、键、重复项/字段、冲突或资源超限整份拒绝；旧配置与运行绑定保持不变。缺失当前命令补兼容默认；如果新增默认与显式绑定冲突，该新项保持未绑定并提示。预览后源文件再变化也不偷换已预览的候选。

缺配置文件正常使用默认。损坏、未来版本或无法读取时可见告警并使用安全默认，原文件受保护；需明确确认重新建立默认配置。写失败会保留旧运行快照。提交后目录同步失败则报告已提交耐久性警告。另一个协作实例修改配置会阻止陈旧覆盖；任意非协作编辑器的竞争仍存在系统边界。

设置不改变制造 revision、工程 dirty、Undo/Redo 或其他偏好。快捷键业务命令保持原事务语义。旧 `.rcam` 不携带快捷键，也无需 schema 升级。

仅 macOS 原生文件选择与工作流在本阶段验收；Windows 原生、另一台真实 Mac 的迁移及完整 V1 另需证据。实际结果以 S5_SHORTCUT_REVIEW 和 versioned exports 为准。
